# हेराउने (Herauney) — नेपाली वैदिक ज्योतिष प्लेटफर्म

नेपालको आफ्नै प्रामाणिक, आधुनिक र पूर्ण वैदिक ज्योतिष वेब अनुप्रयोग। यसले नासा/JPL प्रमाणित खगोलीय गणना (`astronomy-engine`) को आधारमा उत्तर-भारतीय चतुष्कोण लग्न कुण्डली, विंशोत्तरी दशा, नवग्रह स्थिति, र पूर्ण सद्गुरु पण्डित नारायण प्रसाद घिमिरेसँगको प्रत्यक्ष परामर्श प्रदान गर्दछ।

---

## 🌟 मुख्य विशेषताहरू (Key Features)

- **उत्तर-भारतीय चतुष्कोण हीरा कुण्डली (North Indian Diamond Chart):** परम्परागत नेपाली कुण्डली जस्तै अचल रेखाहरू र स्थिर भाव-स्थिति।
- **खगोलीय शुद्धता (NASA/JPL Ephemeris):** VSOP87/ELP2000 मोडेल र लाहिडी अयनांश (Lahiri Ayanamsha) द्वारा सटीक लग्न र ग्रह गणना।
- **वि.सं. क्यालेन्डर र १२-घण्टा ढाँचा:** नेपाली विक्रम संवत् (BS) जन्म मिति र AM/PM समय चयन।
- **नेपालका ७७ वटै जिल्लाको अक्षांश/देशान्तर:** जन्म स्थानको आधारमा स्थानीय सिद्धान्त अनुसार कुण्डली निर्माण।
- **पूर्ण सद्गुरु प्रत्यक्ष परामर्श (Live Vedic Guru Chat):** पण्डित नारायण प्रसाद घिमिरेसँग जीवन, भविष्य, विवाह, करियर, र घरायसी जिज्ञासामा गहिरो र आत्मीय मार्गदर्शन।
- **सुपर एडमिन ड्यासबोर्ड:** प्रयोगकर्ता लिड्स (नाम, फोन नम्बर, इमेल), सोधिएका प्रश्नहरू, र रूपान्तरण विश्लेषण।
- **सुरक्षित संरचना (100% Secure Architecture):** कुनै पनि गोप्य API कुञ्जीहरू वा व्यक्तिगत विवरणहरू Git मा नजाने गरी सुरक्षित `.gitignore` कन्फिगरेसन।

---

## 🚀 प्रविधि (Tech Stack)

- **Frontend:** React 19, Vite, Vanilla CSS Design System, Lucide Icons
- **Backend:** Node.js, Express, Astronomy Engine, Nepali Date Converter
- **AI Engine:** प्रामाणिक वैदिक ज्योतिष एआई इन्जिन (Authentic Vedic Astrology Engine)
- **Deployment:** Vercel (Serverless Full-Stack) / Node.js

---

## ⚙️ स्थानीय वातावरणमा चलाउने तरिका (Local Setup)

```bash
# १. डिपार्टमेन्ट इन्स्टल गर्नुहोस्
npm install

# २. वातावरण चर (Environment Variables) तयार गर्नुहोस्
cp .env.example .env
# .env मा आफ्नो ANTHROPIC_API_KEY राख्नुहोस्

# ३. सर्भर र फ्रन्टइन्ड सँगै चलाउनुहोस्
npm run dev:all
```

- **Frontend:** `http://localhost:5173`
- **Backend API:** `http://localhost:5001`

## ☁️ Vercel मा सुरक्षित होस्टिङ (Vercel Deployment Guide)

1. GitHub मा कोड पुश गर्नुहोस् (`.env` र `server/data/*.json` गिटमा **कहिल्यै जाँदैन**, यो `.gitignore` मा सुरक्षित गरिएको छ)।
2. [Vercel Dashboard](https://vercel.com) मा जानुहोस् र आफ्नो GitHub Repository इम्पार्ट (Import) गर्नुहोस्।
3. **Environment Variables** सेक्सनमा गएर निम्न कुञ्जीहरू राख्नुहोस्:
   - `ANTHROPIC_API_KEY`: तपाईंको वास्तविक API कुञ्जी (`sk-ant-...`)
   - `SUPER_ADMIN_PASSWORD`: तपाईंको गोप्य सुपर एडमिन पासवर्ड
   - `ADMIN_SECRET_KEY`: एडमिन प्रमाणीकरण कुञ्जी
4. **Deploy** मा क्लिक गर्नुहोस्। Vercel ले फ्रन्टइन्ड र ब्याकइन्ड दुवैलाई स्वचालित रूपमा सर्भरलेस रूपमा चलाउनेछ!
